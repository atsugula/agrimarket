# AgriMarket · prototipo navegable

Archivo de diseño editable en Figma: https://atsugula.github.io/agrimarket/AgriMarket_Diseno_Interactivo.html

Este prototipo académico demuestra la navegación del MVP de AgriMarket: catálogo, búsqueda, filtro por categoría, detalle de producto, solicitud y seguimiento, registro/login de muestra y panel de productor con alta, edición y activación/desactivación de productos.

## Abrir

1. Descomprime el paquete conservando juntos `index.html`, `styles.css` y `app.js`.
2. Abre `index.html` en un navegador moderno.
3. Para explorar como productor, selecciona **Mi espacio** y usa la navegación de demostración. Para volver al catálogo, selecciona **Explorar**.

No requiere instalación ni servidor para recorrer el prototipo. La fuente tipográfica remota puede usar fuentes de reserva cuando no haya conexión.

## Alcance de la demostración

- Los datos de catálogo son ejemplos ficticios.
- Registro y login no crean cuentas ni autentican personas.
- Solicitudes se guardan solo en `sessionStorage` durante la sesión del navegador.
- No hay pagos, contacto real con productores, backend ni persistencia productiva.
- El prototipo no reemplaza la prueba de usabilidad con personas objetivo. El informe incluye el protocolo y las plantillas para registrar resultados reales.
